# Catálogos

Use `Layout_Catalogos.xlsx` para establecer los códigos que usarán los layouts de usuarios y operación. La carga se prepara por Gerencia.

Complete las hojas en este orden: `GERENCIAS`, `MATERIAS`, `SEDES`, `PRIORIDADES`, `TIPOS_EXPEDIENTE`, `ORGANOS` y `TIPOS_AUDIENCIA`.

Los códigos son referencias estables. No reutilice un código para un registro distinto ni cambie un código después de usarlo en usuarios, expedientes, audiencias o términos. Los valores `activo` aceptan únicamente `true` o `false`.

Los catálogos de tipos de audiencia deben asociarse a una Gerencia. Las materias también requieren una Gerencia. Los códigos de órgano, sede, prioridad y tipo de expediente deben coincidir con las referencias usadas por los archivos operativos.
