Asunto: Solicitud de pruebas funcionales del SIAJ por rol de usuario

Estimada Dirección de Jurídico:

Por este medio les informamos que ya se encuentran disponibles en el sistema las funciones principales y los ajustes solicitados durante la etapa reciente de validación. Después de revisar la implementación actual del proyecto y validar la compilación del sistema, podemos confirmar que el ambiente ya está listo para una nueva ronda de pruebas funcionales por parte del área usuaria.

Actualmente ya se encuentran habilitados los siguientes componentes y flujos principales:

- Gestión de expedientes con control por rol y alcance operativo.
- Registro y seguimiento de términos.
- Registro y seguimiento de audiencias.
- Creación de expedientes por parte del rol Abogado, quedando asignado como responsable en su propio flujo.
- Captura de términos bajo dos esquemas: por expediente y por asunto único.
- Captura de audiencias bajo dos esquemas: por expediente y por asunto único.
- Avance de etapas, conclusión de registros, observaciones y bitácora operativa.
- Descarga y exportación de información en módulos principales.
- Validaciones de acceso por rol para evitar consulta o modificación fuera del alcance autorizado.
- Mejoras de navegación para uso web y visualización adaptable en pantallas móviles.

Con el fin de cerrar la validación operativa, solicitamos su apoyo para que cada usuario realice las pruebas que le correspondan conforme a su rol. Para facilitar este proceso, se anexa una matriz de pruebas por rol, en la cual se indica qué módulos debe revisar cada perfil y cuál es el resultado esperado en cada caso.

Es importante que las pruebas se ejecuten respetando el perfil asignado a cada usuario, ya que varias de las validaciones incorporadas dependen precisamente del alcance operativo definido para cada rol. De esta manera podremos confirmar no solo que los módulos funcionan, sino también que cada usuario visualiza, captura y administra únicamente la información que le corresponde.

Les agradeceremos que, una vez concluidas las pruebas, nos compartan sus observaciones, comentarios o incidencias detectadas, indicando de ser posible el módulo, la acción realizada y el resultado observado, para atender cualquier ajuste adicional de manera puntual.

Quedamos atentos a su retroalimentación para continuar con la fase de validación final del sistema.

Saludos cordiales.
